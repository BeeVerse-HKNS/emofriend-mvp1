本看板由 TRAE Code 協助開發，採用單文件 HTML 架構，所有 CSS 與 JavaScript 內嵌於同一檔案，無任何外部依賴，可直接於瀏覽器開啟離線運行。

與 EmoFriend 兒童端共享 NLP 情緒詞典（500+ 情緒詞彙）與 CASEL 五大能力框架，但家長端 / 教師端為獨立實作，聚焦於數據視覺化與教學決策支援。

  • 純原生 HTML + CSS + JavaScript，零框架依賴
  • SVG 自繪圖表：成長曲線、雷達圖、熱力圖、迷你走勢圖
  • 繁體中文（香港）+ 英文技術術語雙語呈現
  • 響應式設計：桌面 1280px / 平板 768px / 移動 480px
  • B2B 專業風格：綠 + 橙雙主色，有別於兒童端紫色
  • 與 emofriend-demo.html 代碼重疊率 < 30%（獨立 CSS / JS 命名）
